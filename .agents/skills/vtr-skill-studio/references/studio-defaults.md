# Studio defaults

## Primary mission

Create and improve reusable Skills for VTR production, video editing, and audio correction. Start from school-safety committee assessment, then adapt the same production core to other topics.

## Default language and style

- Thai narration and on-screen text
- Formal, credible language for committee work
- Clear evidence-led storytelling
- Restrained transitions and effects
- School identity preserved from source assets

## Default technical master

- 1920x1080, 16:9, 30 fps
- H.264 video, AAC stereo, MP4
- FFmpeg for deterministic media processing
- Remotion for reusable motion graphics when needed
- Captions delivered as SRT and optionally burned into the video
- Five-to-ten-second safety margin below any hard duration limit

## Default operating rule

Use the current uploaded rubric or brief as authoritative. If no formal rubric exists, agree on audience, purpose, duration, required sections, and acceptance checks before final production.
