# Computer Control

ใช้ทักษะนี้เมื่อผู้ใช้ขอให้ทำงานบนคอมพิวเตอร์ Windows เช่น เปิดโปรแกรม จัดการไฟล์ ตั้งค่าโปรเจ็ก ตรวจสอบหน้าจอ หรือทำงานซ้ำผ่านส่วนติดต่อผู้ใช้

## เครื่องมือหลัก

- ตรวจเครื่องมือและการเชื่อมต่อในแชตปัจจุบันก่อน เลือกเครื่องมือที่เข้าถึงคอมพิวเตอร์เป้าหมายได้จริง
- ใช้ Windows-MCP ชื่อ `windows-mcp` เมื่อเชื่อมต่ออยู่ หรือ computer-use/remote-desktop ที่ระบบเปิดให้และผู้ใช้อนุญาตแล้ว โดยอ่านคู่มือของเครื่องมือนั้นก่อนใช้ ไม่ผูกกับชื่อเซิร์ฟเวอร์เดียว
- บน ChatGPT เว็บหรือมือถือ ทักษะนี้ไม่สร้างการเชื่อมต่อกับ Windows เอง ถ้าไม่มีช่องทางเข้าถึงเครื่องเป้าหมาย ให้แจ้งข้อจำกัดและดำเนินส่วนที่ไม่ต้องควบคุมเครื่องต่อ ห้ามอ้างว่าคลิกแอปหรือแก้ไฟล์ในเครื่องแล้ว
- ตรวจสอบสถานะเครื่องมือก่อนเริ่ม
- ทำงานเป็นช่วงสั้น ๆ และตรวจผลหลังแต่ละช่วง

## หลักความปลอดภัย

หยุดและขอให้ผู้ใช้ดำเนินการเองเมื่อพบ:
- รหัสผ่าน, PIN, OTP, CAPTCHA หรือ Passkey
- การยืนยันบัญชีหรืออนุมัติสิทธิ์ OAuth
- การลบถาวร
- การเผยแพร่สู่สาธารณะ
- การเปลี่ยนสิทธิ์แชร์ไฟล์หรือโฟลเดอร์
- การชำระเงินหรือธุรกรรมทางการเงิน

## ขั้นตอนมาตรฐาน

1. ตรวจว่าเครื่องมือควบคุมคอมพิวเตอร์เชื่อมต่อและเข้าถึงเครื่องเป้าหมายได้จริง
2. เปิดแอปหรือหน้าต่างเป้าหมาย
3. อ่านสถานะหน้าจอก่อนดำเนินการ
4. ทำคำสั่งทีละช่วง
5. ตรวจผลและบันทึกข้อผิดพลาด
6. สรุปสิ่งที่ทำสำเร็จและสิ่งที่ต้องให้ผู้ใช้ยืนยัน
