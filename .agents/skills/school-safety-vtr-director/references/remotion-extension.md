# Remotion extension

Use Remotion only when animated charts, evidence cards, lower thirds, or a reusable branded template materially improve the VTR.

1. Keep raw-media correction and audio preparation in FFmpeg.
2. Create a 1920x1080, 30 fps composition with duration derived from approved scene data.
3. Store editable scene text, media paths, and timing in typed props or JSON.
4. Use frame-based Remotion animation; do not use CSS animations or transitions.
5. Keep animations short and restrained for committee viewing.
6. Render an intermediate or final H.264 MP4, then run the same duration and stream checks as the FFmpeg workflow.

Load the installed `remotion-best-practices` skill before creating or editing Remotion code.
