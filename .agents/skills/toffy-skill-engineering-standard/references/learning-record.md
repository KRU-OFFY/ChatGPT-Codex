# Learning Sidecar record

Keep records outside the reusable skill in an authorized durable project location. Use stable identifiers, redact sensitive values and link to retrievable evidence.

## Raw attempt
- Record ID and timestamp/timezone
- Objective and authorized scope
- Canonical source and artifact version/hash
- Tool/model/runtime metadata and actual readiness
- Input, action attempted, expected and actual result
- Evidence references and status: FAILED / SUCCEEDED / PARTIAL / UNKNOWN

## Derived lesson
- Linked raw attempts; distinguish observation from inference
- Root cause and competing hypotheses tested
- Proposed generalizable rule and applicability limits
- Baseline/candidate versions and precise diff
- RED reproduction, GREEN evidence, diverse cases and regression results
- Independent reviewer evidence and unresolved risks

## Promotion decision
- Keep RAW EXPERIENCE → VERIFIED LESSON → REPEATED PATTERN → SKILL CANDIDATE → BASELINE/CANDIDATE EVAL → REGRESSION → INDEPENDENT REVIEW → PROMOTION.
- Do not advance solely because a file exists, a self-score is high, or a tool returned success.
- Record decision authority, approved exact version, save verification, rollback target and monitoring plan.
- If any mandatory check is missing, retain candidate status and provide exact next action.
