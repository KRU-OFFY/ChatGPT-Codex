# Browser Control

ใช้ทักษะนี้เมื่อผู้ใช้ขอให้เปิดเว็บไซต์ ตรวจระบบเว็บ กรอกแบบฟอร์ม อัปโหลดไฟล์ ทดสอบหน้า Dashboard หรือทำงานผ่านเว็บเบราว์เซอร์

## เครื่องมือหลัก

- ตรวจเครื่องมือที่ใช้งานได้จริงในแชตปัจจุบัน เลือก connector ของบริการเมื่อทำงานได้ตรงกว่า หรือเครื่องมือควบคุมเบราว์เซอร์ที่รองรับการอ่านหน้าเว็บ คลิก และกรอกข้อมูล
- ใช้ Microsoft Playwright MCP ชื่อ `playwright` เมื่อเชื่อมต่ออยู่ หรือเครื่องมือ browser/computer-use ที่ระบบเปิดให้ โดยอ่านคู่มือของเครื่องมือนั้นก่อนใช้ ไม่กำหนดว่าต้องมีเซิร์ฟเวอร์ชื่อเดียวเท่านั้น
- บน ChatGPT เว็บหรือมือถือ ทักษะนี้ไม่ติดตั้งเครื่องมือควบคุมเบราว์เซอร์เอง ถ้าไม่มีเครื่องมือโต้ตอบหน้าเว็บ ให้แจ้งข้อจำกัดและทำส่วนที่ไม่ต้องคลิกเว็บต่อ ห้ามอ้างว่าดำเนินการบนเว็บแล้ว
- ใช้โครงสร้างหน้าเว็บและ accessibility snapshot เป็นหลัก
- ตรวจ URL และชื่อหน้าให้ตรงก่อนคลิกหรือกรอกข้อมูล

## หลักความปลอดภัย

หยุดและขอให้ผู้ใช้ดำเนินการเองเมื่อพบ:
- รหัสผ่าน, PIN, OTP, CAPTCHA หรือ Passkey
- OAuth consent หรือการยืนยันสิทธิ์บัญชี
- การ Deploy/Publish ขั้นสุดท้าย
- การเปลี่ยนสิทธิ์แชร์ข้อมูล
- การลบข้อมูลถาวร
- ธุรกรรมทางการเงิน

## ขั้นตอนมาตรฐาน

1. ตรวจว่ามีเครื่องมือโต้ตอบเบราว์เซอร์ที่เชื่อมต่ออยู่จริง
2. เปิด URL เป้าหมาย
3. ตรวจชื่อหน้า URL และองค์ประกอบสำคัญ
4. ดำเนินการทีละช่วง
5. ตรวจข้อความสำเร็จหรือข้อผิดพลาด
6. ถ่ายภาพหรือเก็บหลักฐานเมื่อจำเป็น
7. สรุปสถานะพร้อม URL หรือผลทดสอบ
