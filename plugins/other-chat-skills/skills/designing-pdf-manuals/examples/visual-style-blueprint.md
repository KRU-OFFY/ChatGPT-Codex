# Visual Style Blueprint

This blueprint captures the useful design language extracted from the supplied reference manual pages without embedding or copying the original reference images.

## Visual DNA

- Strong navy structural bands and page headers
- Orange step numbers, dividers, emphasis, and key labels
- White/light-gray content field for high print readability
- Large Thai page title with one dominant action or topic
- Realistic or realistic-virtual hero visual tied directly to the procedure
- Narrow checklist panel beside the main visual
- Numbered action rows with simple line icons
- Bottom summary/checklist/reference panels
- Stable dark footer with page number and release/safety note

## Recommended Layout Ratios

### Procedure page
- 55–65%: main image / realistic virtual scene
- 25–35%: step checklist or diagnostic panel
- 10–20%: note, result, warning, or mini table

### Architecture page
- 60–70%: primary architecture diagram
- 25–35%: component glossary/checklist
- bottom strip: 2–3 insight or control cards

### Cover
- top 25–30%: title system and edition badge
- middle 45–55%: hero visual
- lower 15–20%: 3–4 feature blocks
- footer: audience/value strip

## Adaptation Rule

Preserve the visual logic, not the subject matter. Replace vehicle/air-conditioning imagery with visuals that accurately represent the new manual's domain. Do not copy brand marks, proprietary labels, or exact compositions when a new design can express the same hierarchy.
