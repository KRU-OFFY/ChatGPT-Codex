# Capability matrix

| Request | Recommended Skill form | Production engine |
|---|---|---|
| Analyze rubric, write script, create storyboard | Instruction-only | None required |
| Trim clips, correct exposure, change volume | Script-backed | FFmpeg |
| Add logo, captions, narration, music, audio ducking | Script-backed | FFmpeg |
| Animated titles, charts, evidence cards, reusable theme | Code-backed | Remotion |
| Complete VTR from raw media to MP4 and QC | Hybrid | FFmpeg + Remotion as needed |
| Continue manual editing in an NLE | Handoff Skill | EDL/XML/project instructions |

Prefer the smallest form that reliably completes the job. Add scripts when deterministic output or repeated editing is required.

## Supported topic families

- School-safety assessment
- School introduction and institutional profile
- Project or activity performance report
- PA/DPA evidence presentation
- Best Practice and innovation presentation
- Academic evaluation and internal quality assurance
- Public relations and event recap
- Training, campaign, or community partnership VTR
- General short documentary or presentation VTR
