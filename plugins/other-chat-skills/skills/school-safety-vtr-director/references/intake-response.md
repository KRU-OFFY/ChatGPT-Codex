# Intake response

After receiving new information, use this compact Thai response and continue working where possible:

```text
รับข้อมูลแล้ว: [รายการใหม่แบบสั้น]
รายการซ้ำ: [จำนวนหรือ “ไม่มี”]
สถานะโครงการ: [ขั้นปัจจุบัน]
ดำเนินการอัตโนมัติ: [สิ่งที่ทำเสร็จแล้ว]
ยังขาด: [เฉพาะตัวขัดขวางสำคัญ หรือ “ไม่มี”]
```

Do not ask the user to choose a Skill, rename files, select a workflow stage, or restate the project goal. Do not present menus unless a material creative choice has multiple genuinely different outcomes.

When the new input removes a blocker, update `project-state.json`, continue to the next safe stage, and report the result rather than asking “Would you like me to continue?”
