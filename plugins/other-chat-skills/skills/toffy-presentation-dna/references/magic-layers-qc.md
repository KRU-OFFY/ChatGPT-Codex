# Canva Magic Layers readiness checklist

Operational sequence (verify actual host capability before use):

`NATURAL COMPOSITION → CLEAN SEMANTIC REGIONS → CANVA MAGIC LAYERS → TEXT AUTHORITY PASS → POST-TAP GEOMETRY QC → VISUAL / LAYER QC`

## Conditional example production target
- 16:9
- 3840 × 2160 px
- PNG
- sRGB
- Noto Sans Thai in the historical example; use the current STYLE_CONTRACT font when supported and verify rendering.
- Use this as the agreed TOFFY image-to-Canva workflow target unless the current brief explicitly specifies a different canvas. Record actual native output separately from the target and any resized derivative.

## Critical Thai text
- Start around 48 px at 2160h when width/headroom is constrained.
- Avoid about 35 px and below for critical text unless separately validated.
- 65 px can reduce OCR correction burden but is conditional; it caused repeatable post-correction reflow in validation.
- “Larger = safer” is not a valid rule.

## Separation baseline
- Text clear zone: ~1.0× Thai glyph height.
- Critical text overlap: 0%.
- Critical text/background contrast target: ≥ 7:1.
- Panel separation: ~32 px at 4K.
- Decoration clearance: ~2.0× glyph height from critical text.
- Photo boundary: crisp and visually unambiguous.
- Never use a generated/approximate school logo when an official logo is required.

## Text Authority Pass
Check exact wording, numeric prefixes, English terms, punctuation, missing units, duplicate/ghost text, and truncation.

## Post-correction geometry QC
Check overflow, clipping, body/footer collision, panel intrusion, hierarchy, and mixed-script title fit. Validation observed repeated title expansion up to about 2.66×, so geometry must be inspected, not assumed.

## Photo-region rule
A visually clean photo region can still fragment into multiple editable fills. Inspect converted fills when one contiguous replaceable photo is operationally important.
