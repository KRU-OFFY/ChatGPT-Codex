# Presentation correction and learning loop

Use this with the current TOFFY Skill Engineering Standard. Keep raw records outside the reusable skill in an authorized durable project sidecar; never store student data, secrets or real personal data in reusable lessons.

1. Before work, retrieve lessons applicable to the current failure pattern and inspect their evidence/status. Rebind the latest canonical project and skill versions. If records are unavailable, report that limitation; do not invent a historical result.
2. Record a stable incident ID, timestamp/timezone, user instruction, authorized scope, source/artifact version or hash, runtime readiness, attempted action, Expected vs Actual, error and retrievable evidence. Separate instruction defects from permission, quota, network, source and runtime limits. Mark missing outcomes UNKNOWN.
3. Investigate Observe → Hypothesis → Test → Evidence → Decision. Reproduce the failure as RED where feasible; preserve baseline and acceptance criteria. Record a hypothesis as a hypothesis until tested.
4. Apply the smallest generalizable fix. Test GREEN plus structurally different cases, negative paths, triggering behavior and regression. Label synthetic results explicitly; never equate them with live Canva, playback or audio success.
5. Obtain independent evaluation with clean context and raw artifacts. Preserve baseline/candidate versions and rollback. If that evaluation or integration evidence is missing, retain CANDIDATE/PARTIAL, not proven improvement.
6. Save authorized skill updates through Skill Creator and verify the saved content freshly. Keep sidecar records and canonical deck state distinct from the skill. A saved rule is not model retraining.
7. During later related tasks apply the lesson, record whether it helped, and feed verified recurrence back into the sidecar. Do not promise an error cannot recur.

## Relevant safeguards to exercise

- Rejected image version: correct and re-review before Canva; preserve approved unchanged pages.
- Altered person/logo: compare with canonical real source; block evidence acceptance until corrected.
- Missing slide, audio or motion: report exact coverage and resume the missing stage.
- Smaller native image: disclose measured resolution; do not claim native 4K from a filename or upscale.
- Tool quota/network failure: checkpoint and block the required stage; do not permanently rewrite the workflow to hide the limitation.
- Post-OCR text expansion: repeat geometry QC after correction before motion/export.
